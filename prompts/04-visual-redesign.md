# 04 — Redesign from a Visual Reference

Purpose: Translate an available visual reference into a polished responsive interface without losing working behavior.

## Copyable prompt

```text
Read AGENTS.md, README.md, the design documentation, and the relevant Vue components. Inspect the supplied visual reference before editing; if the reference itself is unavailable, stop and request it rather than inventing details from a missing annotation. Redesign the interface to capture the reference's layout hierarchy, spacing, typography, color, imagery, and responsive behavior while keeping the experience recognizable as a clean modern travel site. Preserve all working search, hotel-detail, room-selection, booking, and confirmation behavior. Prefer small reusable Composition API components, large hotel imagery, simple navigation, fast interactions, and minimal animation or clutter. Reuse existing assets and dependencies, keep mock values out of components where practical, and request approval before changing packages. Run frontend lint and build checks, inspect the relevant desktop and mobile views, exercise the preserved flows, and report visual differences or behavior that could not be verified.
```
